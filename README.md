# java-oop
# 实验二：面向对象编程

## 实验目标
掌握类与对象、继承、多态、接口、抽象类等面向对象核心概念。

## 实验要求
1. 设计一个「图书管理系统」类层次结构
2. 基类Book包含属性：书名、作者、ISBN、价格，方法：displayInfo()
3. 子类EBook继承Book，增加文件大小属性，重写displayInfo()
4. 子类PaperBook继承Book，增加重量属性，重写displayInfo()
5. 定义Borrowable接口，包含borrow()和returnBook()方法
6. 编写测试类创建不同类型的书并演示借阅流程
